# Marketplace Microservices

A microservices-based marketplace platform where customers can create or join purchase requests for items, sellers can submit offers, and administrators approve offers before sellers receive authorized customer contact information.

## Tech Stack

- Java 21
- Spring Boot
- PostgreSQL
- Docker
- Docker Compose
- RabbitMQ
- Kubernetes
- Terraform
- GitHub Actions
- Prometheus & Grafana

## Services

- Auth Service
- Customer Service
- Seller Service
- Request Service
- Offer Service
- Admin/Contact Service
- Notification Service
